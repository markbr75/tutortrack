# Incident communications

1. Within 15 minutes of a customer-visible incident: update the status page and post a
   platform notice from the console (Operations → Notices). Severity "outage" when a core
   flow (sign-in, scheduling, invoicing, payments) is down; "warning" when degraded.
2. Update every 30 minutes, even if nothing changed.
3. When resolved: end the notice (set its end time), mark the status page resolved.
4. Within 5 working days: a post-incident review (timeline, cause, fixes) and an email to
   affected owners if data or money was affected.
