# E17 — Leads, enquiries and sales pipeline: manual tests

**Scope.** Enquiry capture (hosted forms, the public enquiry API, inbound email, manual phone entry), the configurable pipeline and Kanban board, SLA alerts, trial lessons, conversion into a client and jobs, the waitlist with time-limited offers, registration forms with a fee, funnel reports and (Phase 2b) proposals with online acceptance. Spec: [E17](../epics/E17-leads-pipeline.md).

**Built differently from the spec (Implementation notes win):**
- Forms have no file-upload field; consent wording is a form setting. The hosted form lives on the admin app at `/f/<slug>`; embeddable widgets are E24.
- The default pipeline is created on first use: New (24 h SLA), Contacted (72 h), Trial booked, Trial done, Won, Lost.
- `POST /api/v1/public/enquiries` is protected by Turnstile and a honeypot (no API key).
- Setting up a recurring series at conversion is done afterwards from the job (E08).
- "Capacity appears" suggestions beyond the job-ended alert come from E19 matching.
- Proposals (T09): conversion and the deposit happen in the accept request; the deposit is an E10 payment request paid on the E11 pay page. Packages are plain priced lines.
- Facebook/Google Lead Ads are not built (Phase 3).

**Common preconditions.**
- Stack running and seeded (see [README](README.md)). Sign in at http://brightminds.localhost:5173. Password for every seeded account: `SEED_ADMIN_PASSWORD` (default `tutortrack`).
- The seeded organisation is on its trial, which carries the Agency plan's features, so the `pipeline` feature (Leads) is on. If **Enquiries** is missing from the navigation, check **Settings → Plan** (or the platform console flags) before failing a test.
- Turnstile keys are empty locally, so no CAPTCHA is shown. Emails arrive in Mailpit (http://localhost:8025).
- Most notices (acknowledgement, owner notice, SLA alert, offer expiry, proposal reminders) run in Temporal workflows. Since E33 the acknowledgement, owner notice and SLA alert come from the **Enquiry follow-up** and **Enquiry stage time limits** built-in workflows, and the trial follow-up from **Trial lesson follow-up** (see [E33](E33-workflow-designer.md), TP-E33-048–051); `leads.acknowledge` and `leads.trial_follow_up_hours` are read-only, the stage SLA hours stay on the pipeline. Run the Temporal worker (`uv run python manage.py temporal_worker --task-queue all`) and watch http://localhost:8233.
- No enquiry form is seeded: TP-E17-001 creates "Website enquiry" (`website-enquiry`), which later cases reuse.
