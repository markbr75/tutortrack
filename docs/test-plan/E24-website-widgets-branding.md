# E24 — Public website, widgets and white-labelling: manual tests

**Scope.** The brand kit (organisation and branch) applied to the admin app, portals, emails, PDFs, widgets and the website; custom domains with DNS verification and automatic TLS; embeddable Web Component widgets (tutor directory, enquiry form, services, reviews, login, vacancies, booking, class catalogue, referral, cookie consent) and the WordPress plugin; the hosted website builder with versions, SEO and sitemap; tutor public-profile moderation; and the "Powered by TutorTrack" entitlement. Spec: [E24](../epics/E24-website-widgets-branding.md); decisions in [ADR 0019](../adr/0019-websites-widgets-and-custom-domains.md).

**Built differently from the spec (Implementation notes win):**
- Colours are never rejected for contrast; AA-safe text and link colours are computed and warnings shown.
- Public endpoints resolve the tenant by host (`/api/v1/public/tutors` on `<slug>` host or a custom domain), not `/public/{org}/…`.
- "HTTP verification" is a CNAME check. Themes are five code presets (classic, modern, playful, academic, minimal). The block editor is a form list with move up/down (no drag and drop).
- Invoice styling is the brand colour, logo and footer only (no alternative layouts).
- Booking (`<tt-booking>`, E08) and class catalogue (`<tt-class-catalogue>`, E20) widgets were added by their epics; reviews show collected E25 reviews as well as testimonials.

**Common preconditions.**
- Stack running and seeded (see [README](README.md)); admin http://brightminds.localhost:5173, portal http://brightminds.localhost:5174/portal/. Password: `SEED_ADMIN_PASSWORD` (default `tutortrack`).
- Seed: brand kit (primary #1d4ed8, secondary #0f172a, Inter, email footer "Bright Minds Tutoring · Learning that sticks", Instagram link); three testimonials; approved public profiles for active tutors (Nia Adeyemi); widgets "Tutor directory" (allowed origin http://localhost:5175) and "Reviews"; a published website at **http://brightminds.site.localhost:8010/** (Home, About, Tutors, Contact).
- **Widgets playground:** `pnpm --dir frontend --filter @tutortrack/widgets dev` serves http://localhost:5175 (`frontend/apps/widgets/index.html`), which loads the widgets against `http://brightminds.localhost:8010` with `data-org="brightminds"`. Add http://localhost:5175 to a widget's allowed websites to test it there.
- **Custom domains locally:** the fake DNS resolver verifies any domain (`CUSTOM_DOMAINS_FAKE_AUTO_VERIFY=true`) and the fake certificate provider issues at once. To browse a custom domain, add a hosts-file entry (e.g. `127.0.0.1 www.brightminds.test portal.brightminds.test`) and add the hosts to `DJANGO_ALLOWED_HOSTS`; open them on port 8010. **Caution:** once an *app* domain is active, `Organisation.base_url` and every email link switch to it. Remove the domain after the test.
- `CustomDomainWorkflow` runs in Temporal (http://localhost:8233). Emails in Mailpit.
