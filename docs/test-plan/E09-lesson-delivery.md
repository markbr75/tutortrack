# E09 — Lesson delivery (attendance, cancellations, lesson reports): manual tests

**Scope.** Completing lessons and recording attendance, cancellation policies with a live preview, makeup credits, report templates, lesson reports (draft, submit, approve, return, share, comments), the report SLA and unconfirmed-lesson workflows, and the Phase 2b lesson feedback micro-surveys. Spec: [E09](../epics/E09-lesson-delivery.md).

**Built differently from the spec (Implementation notes win):**
- The permission to complete a lesson is `scheduling.lesson.complete` (no `delivery.lesson.complete`). Balance override needs `delivery.balance.override`.
- Reports are addressed by their own id (`/lesson-reports/{id}`), one report per lesson and tutor. Submitting a report completes a started planned lesson (`delivery.report_submit_completes`).
- Cancellation overrides for a branch, service, job or client exist in the API only; the admin screen edits the organisation policy.
- "Max free cancellations" counts per calendar month, and (G3) per E20 term with `max_free_per_term`. There is no `makeup_credit.expired` event (expiry is derived).
- SLA and unconfirmed lessons run as Temporal workflows (`LessonReportSlaWorkflow`, `UnconfirmedLessonWorkflow`, started by a 15-minute beat task). Feedback surveys run as `LessonFeedbackWorkflow`.
- Topics and homework fields are free lists. Attachments are stored as references.

**Common preconditions.**
- Stack running with Celery worker and Temporal worker (`manage.py temporal_worker --task-queue all`). Seed loaded (`make seed`).
- Org Bright Minds Tutoring (Europe/London, GBP). Arjun Patel has a weekly Tuesday 16:30 GCSE Maths 1:1 job with tutor Nia Adeyemi (60 min, £45/h charge, £28/h pay) and generated lessons.
- To get a lesson in the past, create a one-off lesson in the calendar for Arjun with Nia, today at a time already passed (for example 09:00), or use last Tuesday's lesson.
- Admin screens: `/calendar` (lesson quick view: **Mark completed**, **Cancel lesson**, **Write report**), `/reports` (Lesson reports), `/unconfirmed`, `/lesson-policies`, `/lesson-feedback`. Tutor portal: `/portal/tutor`, `/portal/tutor/lessons/<id>`, `/portal/tutor/lessons/<id>/report`.
