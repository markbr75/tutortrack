# E21 — Learning tools: progress, homework, resources and assessments: manual tests

**Scope.** Resource library with sharing and view tracking, homework (assign, hand in, review, grade, return, reminders, overdue), curricula with topic tagging and mastery, goals with milestones, assessments with score trends, progress reports (generate, approve, share as PDF), the lending library, and built-in quizzes (Phase 3b). Spec: [E21](../epics/E21-learning-tools.md); decisions in [ADR 0025](../adr/0025-learning-tools-on-existing-seams.md).

**Built differently from the spec (Implementation notes win):**
- Progress reports are generated by staff (no per-organisation schedule); approval is a plain status change.
- The AI draft of the progress summary is available once E31 registers a drafter (it does, with the fake provider in dev).
- FR-21-8 (sending resources into video rooms) is not built; lesson shares publish `resource.shared` for later.
- Quizzes are built; the E18 tutor subject-test UI is not.

**Common preconditions.**
- Stack running and seeded (see [README](README.md)); admin http://brightminds.localhost:5173, portal http://brightminds.localhost:5174/portal/. Password: `SEED_ADMIN_PASSWORD` (default `tutortrack`).
- Seed: curricula **GCSE Maths** and **KS2 English** installed; resource "Equivalent fractions explained" (link, tutors, tag fractions) shared with the first seeded student (Arjun Patel); homework "Fractions worksheet" (text, due in 5 days at 18:00, set by Nia); goal "Grade 7 in GCSE Maths" (current 5, three milestones, one done); assessment "Autumn mock (paper 1)" with Arjun's 54/80, grade 6; library item "CGP GCSE Maths revision guide" (3 copies, £7.99) lent to Arjun.
- Logins: tutor@ (Nia, teaches Arjun), parent@ (Priya Patel), student@ (Arjun).
- Temporal worker running for homework and loan reminders (http://localhost:8233). Emails in Mailpit.
